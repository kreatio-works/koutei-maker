# 工程表メーカー

工種・開始日・日数を入れるだけで、日単位の工程表（バーチャート）を描き、
**Excel（.xlsx）出力** と **印刷／PDF** ができる単一HTMLアプリです。
サーバー不要・インストール不要。ブラウザだけで動きます。

## できること

- 工種ごとに「区分・開始日・日数・備考」を入力 → 終了日を自動計算
- 日曜・祝日を作業日に含めない設定（含めない日は飛ばして日数を数える）
- 祝日は年を指定して自動計算（振替休日・国民の休日を含む、2000〜2099年）
- 工種の区分ごとに色分け（淡色パレット12色）、全体の鮮やかさ・明るさをまとめて調整
- 気に入った配色を「配色パターン」として記憶・呼び出し
- 複数の工程表を切り替えて管理（新規・複製・削除）
- Excel出力：色付きセル・罫線・月/日/曜日の3段ヘッダ・凡例・A3横1枚の印刷設定つき
- 印刷／PDF：ブラウザの印刷機能でA3横に出力
- 入力内容はブラウザに自動保存。JSONで控えの保存・読み込みも可能

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages で公開すればスマホからも利用可）
2. 「入力」枠で工事名と工種を入力。下の「プレビュー」に即時反映されます
3. 「設定」枠（折りたたみ）で祝日の取り込み・区分の色を調整
4. プレビュー枠の「Excel出力」または「印刷 / PDF」

## 技術メモ

- 単一HTML（HTML / CSS / JavaScript）。外部依存は Excel 出力用の [ExcelJS](https://github.com/exceljs/exceljs)（cdnjs から読み込み）のみ
  - SheetJS の無料版はセルの塗り・罫線を書き出せないため ExcelJS を採用
- 保存先は `localStorage`（キー `koutei-maker-v3`）。旧版キー（v1/v2）からは自動移行
- Excel の出力は関数を使わず書式のみのため、Excel 2016 以降で問題なく開けます
- 祝日計算：日付固定＋ハッピーマンデー＋春分/秋分（近似式）＋振替休日＋国民の休日
  - 臨時の祝日変更（例：2020年の五輪特例）は追えないため、その場合は手で追加・削除
